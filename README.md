## Reproduction Instructions

### Prerequisites
- [Foundry](https://book.getfoundry.sh/) (`forge`, `cast`)
- Active internet connection to reach an Ethereum mainnet archive/full node RPC (e.g. Tenderly gateway, Blockrazor, or custom node)

### 1. Build
```bash
forge build
```

### 2. Run Test Suite
To run all tests against the mainnet fork:
```bash
forge test -vvv
```

Or run individual test modules:
```bash
# 1. Deposit & Yield Routing flow
forge test --match-test test_DepositAndYieldRoutingFlow -vvv

# 2. Safe Yield Realization & Deep SEAT Refund flow
forge test --match-test test_YieldRealizationAndDeepRefund -vvv

# 3. Negative Tests (!keeper and diverted yield)
forge test --match-contract NegativeTests -vvv
```

To run with a custom RPC endpoint:
```bash
ETH_RPC_URL="https://your-custom-rpc-url" forge test -vvv
```

## Key Invariants Verified

1. **Yield-Donating Mechanism**:
   Octant strategies **never inflate the share price** (PPS remains constant at 1:1). Profit generated by the strategy is minted as **new donation shares** exclusively to the `donationAddress` (`PEN Safe`).
2. **Yield Quarantine & Protection**:
   Yield generated by the strategy does not enter `PrincipalManager.totalManagedAssets()` until the PEN Safe explicitly redeems its donation shares for USDC and sends USDC to `PrincipalManager`. This prevents premature spend and unbacked surplus.
3. **Deep SEAT Refunds**:
   Even if `PrincipalManager` has zero liquid cash (`liquidAssets() == 0`), calling `bondingTranche.refund(...)` automatically triggers `_ensureLiquidity()`, withdrawing USDC from the Octant ERC-4626 strategy to satisfy the refund obligation.
4. **Rounding & Trapped Assets**:
   Accounting tracks integer division rounding (observed at 1 micro-USDC across 500 USDC profit). Zero assets or shares are trapped in the contract.
